# 🏢 Corporate Landing Page - Next.js 16

Bu proje, **Next.js 16** kullanılarak geliştirilmiş, modern, SEO dostu ve tamamen responsive bir kurumsal açılış sayfasıdır (Landing Page). Şirketlerin profesyonel dijital varlıklarını oluşturmak için optimize edilmiştir.

## 🚀 Özellikler

*   **Next.js 16 (App Router):** En güncel React framework özellikleri ve performans iyileştirmeleri.
*   **Performans Odaklı:** Hızlı yükleme süreleri ve yüksek Lighthouse skorları.
*   **Responsive Tasarım:** Mobil, tablet ve masaüstü cihazlarla tam uyumlu.
*   **Modern UI/UX:** Şık animasyonlar ve kullanıcı odaklı tasarım.
*   **SEO Dostu:** Dinamik meta etiketleri ve optimize edilmiş yapı.

## 🛠️ Kullanılan Teknolojiler

*   **Framework:** Next.js 16
*   **Dil:** TypeScript / JavaScript
*   **Stil:** Tailwind CSS (veya senin kullandığın kütüphane: CSS Modules/Sass)
*   **Bileşenler:** Lucide React (İkonlar), Framer Motion (Animasyonlar)
